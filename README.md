# 🩺 Health Risk Predictor (Tkinter + Machine Learning)

## 📌 Overview
This is a desktop-based Health Risk Prediction application built using Python. It uses a Random Forest Classifier to predict whether a person is at health risk based on inputs like age, BMI, blood pressure, sugar level, and gender. The project includes a simple GUI built with Tkinter.

---

## ⚙️ Tech Stack
- Python 🐍  
- Tkinter (GUI)  
- Pandas  
- Scikit-learn  
- Random Forest Classifier  

---

## 🧠 How it Works
The model is trained on a small sample dataset with features:
- Age  
- BMI  
- Blood Pressure  
- Sugar Level  
- Gender  

It predicts:
- ⚠️ Health Risk Detected (1)  
- ✅ You Are Healthy (0)

---

## 🚀 Features
- Simple and interactive GUI  
- Real-time prediction  
- Input validation (prevents invalid values)  
- Clear & reset functionality  
- Beginner-friendly ML project
